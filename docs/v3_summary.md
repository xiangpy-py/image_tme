## 一、版本定位

V3 是当前主力模型，采用**一对多联合建模**：一次训练、一份权重，通过 marker 条件同时覆盖
CD68 / CD45RO / HLA-DR / Vimentin 四个标记。

选择该方案的三个理由：

1. 赛题明确「鼓励一对多生成」，且创新附加分（1–5 分）的判定依据包含
   「是否提供充分实验结果证明联合建模优于单任务方案」；
2. 一次训练覆盖四类标记，总耗时显著低于「每标记各训一个模型」；
3. 跨标记共享表示可复用不同标记间的结构共性。

参数量 **33.67 M**。

---

## 二、模型结构

V3 在 V2（`ConditionalUNetV2`：DoubleConv + 全尺度 FiLM）基础上做了两处升级，
且都通过 `Down` / `Up` 的开关参数控制，是在同一骨干上的增量改造，而非另起炉灶。

| 设计 | 代码位置 | 说明 |
| --- | --- | --- |
| 残差卷积块 | `src/train/models.py:62-100`（`ResidualBlock`） | `residual=True` 全量替换 DoubleConv；任务本质是配对图像重建，残差保留原始空间信息，利于 SSIM/PSNR 像素对齐 |
| 深层 CBAM | `src/train/models.py:103-201`（`ChannelAttention` + `SpatialAttention`） | 通道注意力与空间注意力串联，聚焦细胞区域、组织边界等高响应结构 |
| 全尺度 FiLM | `src/train/models.py:552-584`（`FiLM`） | 编码器每层 + 瓶颈 + 解码器每层均注入 marker 条件；scale 初始化为 1、shift 初始化为 0，以恒等映射起步保证训练稳定 |

**注意力只放深层的开销控制**：`attn_start=2` 表示特征通道数达到
`base_channels << 2 = 256` 的层起才插入 CBAM，浅层保持无注意力。
实测 CBAM 仅占总参数的 **0.213 M**，FiLM 合计 **1.024 M**。

**main 结构**（`ConditionalResAttentionUNet`，`src/train/models.py:797-903`）：

```
DAPI (3ch)
  └─ stem: DoubleConv(3 → 64) + FiLM
       └─ encoder × 4 : [MaxPool → ResidualBlock(×(2)) (+CBAM if ≥256ch)] + FiLM
            └─ bottleneck: FiLM
                 └─ decoder × 4 : [ConvTranspose → skip-concat → ResidualBlock (+CBAM)] + FiLM
                      └─ head: Conv2d(64 → 1) → Sigmoid
```

marker 条件通过 `nn.Embedding(4, 128)` 映射为嵌入向量，再由各层 FiLM 生成
逐通道的 scale / shift。

## 三、训练配方

配置见 `configs/conditional_v3.yaml`。

| 项 | 取值 |
| --- | --- |
| epochs | 150 |
| batch_size | 32 |
| 学习率 | 1.0e-4 → 1.0e-6（CosineAnnealingLR） |
| weight_decay | 1.0e-4 |
| 损失 | `0.35·L1 + 1.0·MSE + 0.35·SSIM + 0.10·Sobel` |
| 增广 | 仅几何（hflip 0.5 / vflip 0.5 / rot90），光度扰动全 0 |
| EMA | 开（decay 0.9999，每 5 轮评估一次） |
| AMP | 开（fp16） |
| torch.compile | **关** |
| 推理 | TTA 开（4 旋转 × 2 翻转 = 8 视几何等价平均） |

**损失设计直接对齐评分口径** `Score = 0.7·SSIM + 0.3·Normalize(PSNR)`：
L1 保颜色与抑制离群、MSE 作为 PSNR 的精确代理、SSIM 对齐主指标、Sobel 梯度项
防止细胞与组织边界模糊。各项权重经消融确定（见第五节）。

**只开几何增广**是 V2 阶段验证过的最大单项收益：本任务是绝对强度回归
（SSIM/PSNR 按像素比），对输入 DAPI 做亮度/对比度抖动等于要求模型对输入
光照不敏感，与任务目标矛盾。实测关闭光度扰动后 15 轮筛选从 0.6558 提升到 0.6864。

训练耗时实测约 **55 s/epoch**，150 轮总计 136 分钟。

## 四、实验结果

### 4.1 总体成绩

| 阶段 | Score | 说明 |
| --- | --- | --- |
| 15 轮筛选（p11_resattn_v3） | 0.6989 | 同期 V2 最好 0.6864、V2 基线 0.6558 |
| **150 轮长训练** | **0.7129** | best 落在 epoch 132，较 15 轮 +0.0140 |
| 逐标记平均（提交口径） | **0.7166** | 全量验证集 + TTA |

> 口径说明：训练日志中的 0.7129 是四标记**混合累计**（`MetricAccumulator`
> 合并 SSE 与像素数后计算一个全局 PSNR）；逐标记评估则先算各标记 Score
> 再取平均，对应赛题「多输出取平均分」的规则，因此 **0.7166 更贴近线上读数**。

### 4.2 逐标记拆解（全量验证集 + TTA）

| 标记 | SSIM | PSNR(dB) | Score |
| --- | --- | --- | --- |
| CD68 | 0.8352 | 25.21 | **0.7737** |
| CD45RO | 0.7216 | 21.67 | **0.6677** ← 短板 |
| HLA-DR | 0.8169 | 19.88 | 0.7209 |
| Vimentin | 0.7904 | 20.10 | 0.7040 |
| **平均** | | | **0.7166** |

CD68 已越过 74 线，CD45RO 是唯一明显短板，与 CD68 相差 **0.106**。

### 4.3 收敛性

| epoch | Score |
| --- | --- |
| 100 | 0.7117 |
| 132（best） | 0.7129 |
| 150 | 0.7118 |

**最后 50 轮仅提升 0.0012**，学习率已退火至 1e-6，训练完全平台化。
这是 V3 不再续训的直接依据——瓶颈不在优化未收敛。

## 五、定向实验记录（以负结果为主）

基于 V3 骨干做的参数定向搜索，全部在 15 轮筛选阶段完成，详见
`configs/experiment_matrix.yaml:95-145`。

| 实验 | 变更 | 15 轮 Score | 结论 |
| --- | --- | --- | --- |
| p11 | V3 基线 | 0.6989 | 参照组 |
| p12 | TV 正则 `match` 模式（λ=0.5） | 0.6945 | 变差 |
| p13 | TV 正则 `penalty` 模式（λ=1.0） | 0.6964 | 变差 |
| p14 | λ_mse = 0.5 | 0.7000 | 微升 |
| p15 | λ_mse = 1.0 | 0.6999 | 微升 |
| p16 | λ_mse = 2.0 | 0.6998 | 微升 |
| p17 | CD45RO 采样权重 ×2 | 0.6980 | 无效 |

**结论**：V3 的调参空间在 15 轮量级已被扫尽，后续尝试均落在噪声带内。

唯一被采纳的改动是把 `lambda_mse` 由 0.20 提升到 1.0（约 +0.001），
它复现了文献中「L1 偏 SSIM、L2 偏 PSNR」的权衡——λ 越大 PSNR 越高、SSIM 略降：

| λ_mse | PSNR | SSIM |
| --- | --- | --- |
| 0.2 | 20.67 | 0.7770 |
| 0.5 | 20.76 | 0.7775 |
| 1.0 | 20.82 | 0.7768 |
| 2.0 | 20.94 | 0.7754 |

0.5~2.0 区间得分持平，取中值 1.0 兼顾两端稳定性。

TV 正则的实验依据来自损失分项量纲实测（四标记平均）：
`L1≈0.046 | MSE≈0.0088 | SSIM≈0.224 | 边缘≈0.065 | TV(预测)≈0.0062`，
其中预测的总变差仅为真值的 1/3，说明模型本身已偏平滑。两种语义相反的写法
（要求结构变化量与真值相当 / 直接抑制总变差）均未带来收益。

## 六、瓶颈诊断

使用 `temp/diagnose_psnr_gap.py` 在 15 轮权重上做拆解（CPU 推理，992 张验证样本）。

### 6.1 输出标定假设被证伪

| 参照口径 | Score |
| --- | --- |
| 模型原始输出 | 0.6999 |
| 常数图 oracle（逐图均值） | 0.5964 |
| 逐图仿射 oracle（完美标定上界） | 0.7037（仅 +0.0038） |
| 全局仿射 oracle（可部署标定） | 0.6978（反而更低） |

逐图仿射只能带来 +0.0038，全局仿射甚至更差，
说明**输出强度标定不是瓶颈**，这条提分路径已被排除。

### 6.2 真实瓶颈是弱标记塌缩

模型相对常数图的整体 R² 仅 **0.2822**，且标记间差异极大：

| 标记 | 相对常数图 R² | 幅度比 std(pred)/std(gt) | Pearson r |
| --- | --- | --- | --- |
| CD68 | 60% | — | — |
| CD45RO | 23% | 0.41~0.57 | 0.54~0.64 |
| HLA-DR | **9%** | 0.41~0.57 | 0.54~0.64 |
| Vimentin | 28% | 0.41~0.57 | 0.54~0.64 |

弱标记的共同征兆是**幅度比显著小于 1 且相关系数偏低**，即典型的
「回归到条件均值」——模型在信息不足时倾向于输出安全的平均值。

### 6.3 根因是信息受限

DAPI（单通道灰度细胞核）到各 IHC 标记的线性 R² 本身只有 **3%~23%**。
因此 0.71 → 0.74 的差距不在结构或超参，而在
「DAPI 中究竟有多少目标标记的可恢复信息」。

## 七、工程教训

### 7.1 torch.compile + fp16 会导致训练静默冻结（最贵的坑）

本机 torch 2.11 下，`torch.compile` 与 fp16 反向组合会产生大规模 NaN 梯度
（探针实测 **105/144 参数为 NaN**），导致 GradScaler 全程跳过
`optimizer.step()`——**训练完全冻结却不报任何错误**，损失看起来正常下降。
最终通过设 `compile: false` 解决。该结论已固化进配置注释。

### 7.2 EMA 在本任务上没有收益

150 轮训练日志中「权重来源=ema」出现 **0 次**，`best.pth` 自始至终来自
原始权重（raw）。EMA 除了不涨分，还因每 5 轮额外评估一次全量验证集
而增加了约 1/5 的验证开销。下一版可考虑关闭。

### 8.2 遗留问题与后续方向

1. **CD45RO 是唯一有明确提升空间的标记**（0.6677，比 CD68 低 0.106）。
   集中资源拉平它比改动整体结构更划算；若把它拉到 CD68 水平，
   四标记均分可达约 0.7528。
2. **单标记对照组尚未完成**。赛题附加分的判定依据中明确要求
   「提供充分实验结果证明联合建模优于单任务方案」，
   这是目前争取加分最欠缺的一块材料，且成本可控（重训若干单标记基线）。
3. **`CrossMarkerConsistencyLoss` 已实现但从未启用**
   （`src/train/losses.py:315`）。它是跨标记信息利用的现成抓手，
   V3 阶段未做验证，可作为下一版的第一个实验点。
